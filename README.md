# ai-weatherman
## Abstract
This piece of Python software will hit read-only weather APIs for real-time weather data and feed the results to an LLM for a 'weatherman-like' response!

## To Get Weather Updates
Download 'ntfy' on app store.
Subscribe to 'sunnyweather'.
Watch and listen for Sunny McSkies!

### Current Support
Currently using Open-Meteo as the weather source.

Currently using Hugging Face and 'gpt-oss-120b' as the LLM or AI-Weatherman.
